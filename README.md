## Данные 
Использовал датасет [Train](https://www.kaggle.com/competitions/demand-forecasting-kernels-only/data) с Kaggle.

## Цель проекта
Предсказать, сколько штук товара продаст магазин за день. Такой прогноз помогает понять, сколько товара стоит заказать.
Я использую данные о продажах с Kaggle. В них есть история продаж 50 товаров в 10 магазинах с 2013 по 2017 год. Каждая строка показывает, сколько штук конкретного товара продали в конкретном магазине за день.

Чтобы запустить проект, скачайте train.csv, положите его рядом с sales_forecasting.ipynb и выполните ячейки по порядку.
